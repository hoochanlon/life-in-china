# 产业繁荣的另一面：制造业宏观攀升与劳动者的劳动贫困

> 在支付工人薪酬方面，中国落后于许多较贫穷的国家。根据联合国工业发展组织（工发组织）的数据，2016年（工发组织可获取的中国数据的最新年份），中国制造业工人的工资仅占制造业总产出的4%。在工发组织当年收集数据的87个国家中，中国的排名倒数第二，仅高于印度尼西亚。远比中国贫穷的印度，其工资占比为5%；而以劳工权益立场不强著称的美国，其工资占比也高达12%。—— Yasheng Huang.

## 1. 竞争优势的来源决定了红利分配方向

国内制造行业的全球领先，很大程度上依靠规模化产能、极致成本控制、全产业链配套和系统效率，而不是不可复制的顶尖核心技术或高度稀缺的专业人才壁垒。普通流水线工人、基础技术岗、运营岗可替代性强，劳动力供给充足，议价权弱。企业利润优先用于巩固市场份额、扩产、研发迭代和资本回报，人力成本被当作最容易压缩的刚性支出。结果是：行业市占率和利润上去了，基层薪资却长期贴近劳动力市场基准线，甚至出现利润暴涨时福利缩水、工时延长的情况。

## 2. 要素密集度与劳动者议价能力的差异

资本和体系主导的行业，核心资产是厂房、设备、供应链和资金规模，而不是普通员工的不可替代性。对比知识密集型行业（高端芯片设计、精密软件、部分研发岗位），人才可以“用脚投票”，企业必须高薪留人。制造业一线则相反。这也解释了为什么硅谷码农待遇远高于传统钢铁工人，以及为什么规模优势行业的红利难以自动向下传导。

## 3. 行业层面的隐性工资协调机制

多数龙头实行资本优先、岗位绩效制，而非普惠的利润共享。利润主要流向股东分红、资本增值和再投资。行业内部还存在“不能主动大幅涨薪、不能高薪挖人”的隐性规则，一旦有企业（如特斯拉中国工厂）尝试提升待遇，就可能被指责“扰乱行业成本秩序”。这进一步锁死了普通员工的上涨空间。企业内部两极分化明显：少数高管、核心研发和资本方拿走大部分红利，占人数九成以上的基层与红利基本无缘。

## 4. 劳动力市场结构性失衡

庞大劳动力供给，以及就业竞争压力，使企业拥有绝对用工主导权。加班文化、绩效克扣、福利压缩成为常态。收入看似“还行”，往往是靠超长工时和透支健康换来的。年轻人已开始拒绝低薪高强度岗位，部分低端制造因此向更低成本地区转移。

## 5. 制度层面的关键缺口

劳动者缺乏有效的集体议价机制。分散的个体面对组织化的企业，议价能力天然不对等。对比韩国等国家，存储芯片行情好时海力士甚至给安保发高额分红，员工组织能推动利润分享；而国内更多依赖企业“良心”或外部压力（如海外市场的劳动合规要求、贸易规则）。一旦海外监管收紧，企业才临时要求“到点下班”。这让打工人的权益保护显得被动和心酸。
